ARLab: An AI Enabled, AR-Guided Platform for Zero-Shot Wet-Lab Procedures
Master's Thesis, Traverso Lab, Broad Institute of MIT and Harvard
July 2026 – January 2027 (ongoing), supervised by Prof. Giovanni Traverso

I am developing an AI-powered AR assistant on Apple Vision Pro to guide wet-lab procedures without task-specific training. It combines computer vision and object tracking with semantic graph-based procedural reasoning and large language models to track object states, spatial relationships, hand–object interactions, and task progress. I am investigating this approach for real-time guidance, mistake detection, and workflow monitoring in biomedical labs.

AI for Joint Angle Monitoring and Movement Classification from TENG Data
Semester Project, BMHT Lab, ETH Zurich
March 2026 – June 2026, supervised by Dr. Corin Otesteanu, Dr. Satyaranjan Bairagi, and Prof. Carlo Menon

I developed joint-angle regression, movement classification, and gait recognition methods using a self-powered triboelectric nanogenerator (TENG) knee sensor. I designed signal processing and feature extraction pipelines, evaluating TabPFN-based models within participants and on unseen participants (leave-one-participant-out). I also tested participant-specific normalization and analyzed sensor artifacts and inter-subject variability to improve robustness. This work contributed to a manuscript submitted to Advanced Fiber Materials.

Keyboard-Typing SO-101: Autonomous Keyboard Typing with a Robot Arm
Course Project (Robot Learning), ETH Zurich
2026

We built an SO-101 robot arm that types on a keyboard using eye-in-hand vision. Roboflow key detection, PnP, and hand–eye calibration locate keys in 3D; quadratic-programming-based inverse kinematics guides a hover, recheck, and press sequence. We evaluated fixed sequences, random keys, and sentences scored by Levenshtein distance. Built on LeRobot, the code also includes a state-only MLP behavior-cloning policy plugin. Joint work with Atakan Topaloglu, Samuel Sutanto, and Arda Cinar Demirtas.

Warping Voxel-grids for 3D Robotic Mapping
Course Project (3D Vision), ETH Zurich
March 2025 – July 2025, supervised by Dr. Daniel Barath

When loop closure updates camera poses, a voxel map must adapt to remain consistent. This project warps the voxel grid to match the corrected trajectory, integrating loop closure optimization into voxel-based 3D robotic mapping.
